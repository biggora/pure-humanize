Why pure-humanize?

Intl-native

Delegates all locale logic to the runtime's built-in Intl APIs. No bundled translations.

Zero Dependencies

Nothing to audit, nothing to update. Pure utility functions only.

Tree-shakeable

ESM-first with sideEffects: false. Import only what you use.

Cross-runtime

Works in Node.js 18+, Deno, Bun, and all modern browsers.
